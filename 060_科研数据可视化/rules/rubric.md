# 060 评分映射与验收 rubric

核心判据：图件真实可用、数值与源数据一致、他人能从随附原始快照重跑，而不是只生成一段建议或一张 PNG。

## 实际效果（40）

- 任务完成度 15：七类图均有执行路径；每图交 PDF/PNG/SVG、绘图 TSV、R 分析、图注、行级 lineage；未完成任务明确为 partial。
- 结果正确性 15：R 正式统计 + Python 独立复核；缺失/重复/小样本/常量相关不伪造数值；拟合区分总体与分组。
- 结果完整性 5：轴、单位、图例、样本量、误差定义、色标、图注、面板与请求格式逐项核对。
- 结果可核验性 5：原始快照 → TSV → R 统计 → 三格式文件的第二次全链运行哈希一致。

## 使用增益（25）

- 质量增益 15：小样本显示原始点，趋势保持顺序，散点颜色+形状，热图带发散 colorbar，无裸均值柱、饼图、3D、 rainbow/jet 或首 N 类截断。
- 效率增益 5：一条命令完成清洗、绘图、三格式、审计和复现；单图失败不阻断其它图。
- 增益可验证性 5：逐图 QA 检查、独立数值重算、真实文件元数据与全链哈希均可复核。

## 创新增益（15）

- 新增能力 5：动态契约 + 图元数据血缘 + 期刊导出预检 + 双端数值核验。
- 方法改进 5：Shell/TSV/R 单向接口，Python 不绘图，R 不读脏原始文件。
- 创新证据 5：合成压力测试覆盖正常与失败路径；正式分数只采用平台真实运行，不自述编造。

## 可靠体验（10）

- 调用与易用性 3：生产命令、工作工单补全、依赖和独立复跑命令齐全。
- 运行稳定性 4：内联表/CSV/TSV/JSON/SQLite，中文标签、时间、缺失、混合类型与多图批量。
- 异常处理 3：非有限数、重复、小样本、零方差、类别过多、缺依赖、单图失败均有真实状态。

## 生态贡献（10）

- 文档完整性 3：用途、输入、输出、依赖、适用边界、异常、自查和示例一致。
- 资源可复用性 4：主题、图型规则、色板、venue、审计器和测试可独立复用。
- 分享推广价值 3：公开仓库应能直接定位本题作品；真实链接填 `GITHUB_URL.txt`。

## 完整状态的必要条件

- 所有请求图件均为 delivered，且无 no_builder/not_plotted/dependency_missing。
- 每图 PDF、PNG、SVG 均实际存在，请求格式全部满足。
- 每图 QA 全过，图注独立可读，三格式元数据通过。
- 每图端到端重跑一致。
- `status.overall`、`状态说明.overall`、逐图状态和缺口清单一致。
